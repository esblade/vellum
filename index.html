Ajustes

Credenciais e dados ficam salvos só neste navegador. Nada é enviado para outro lugar além da API da Pluggy (ou do seu intermediário).

Usar intermediário (Cloudflare Worker)

Use se o navegador bloquear o acesso direto à API. Com o intermediário, Client ID e Secret ficam no Worker e podem ficar em branco aqui.

Aparência e dados
